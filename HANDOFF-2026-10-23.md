# Handoff, 2026-10-23 night: tracker 0.8.11 (accuracy) for testing

Written by a cloud session (no Windows, no game) for the session on Steven's PC. Steven asked for a build to test in the
morning. Everything below is on `main` and was built by GitHub Actions (Build tracker, artifact `kinah-ledger-tracker`).
No tag, no release: Steven tests first, then `git tag v0.8.11 && git push origin v0.8.11` releases it (notes are written).

## What changed

- **Names settled by colour** (`Ocr/NameColour.cs`): each chat read also measures the colour of each line's item name
  from the capture before Boost (`ScreenReader.LastAccents`). Names read exactly teach each grade's colour
  (`GradeColours`, saved to `%LOCALAPPDATA%\KinahLedger\grade-colours.json`). A misread name can then only become an
  item whose grade the colour doesn't rule out (`ChatParser.Choose`, `GradeFilter`). Nothing about the palette is assumed.
- **Names settled by loot tables**: of two items as close as each other, the one on the run or on the loot tables of the
  enemies being fought (target bar + nameplates) wins. A guess (`Via = guessed`) that no table of a known, current
  open-world enemy lists is not counted from the chat (`HeldUnlisted`); the loot list cross-check still adds it if it saw it.
- **Text sizing** (`Ocr/TextScale.cs`): the chat's enlarging factor follows the median word height, aiming at
  `ocr.targetTextPx` (36), never below `ocr.scale` (2), max 4x, quarter steps, 10% hysteresis.
- **Loot list icons** (`Ocr/PopupIcons.cs`): a row whose text isn't an exact item name is compared by icon among the items
  its letters fit (`ItemDictionary.Fragment`/`Near`), using the reward table's fingerprints (`IconIndex.Cell/Distance`,
  refactored out of `RewardGrid.Match` with identical results). Named only when one icon is under 70 and 12 ahead of the next.
- **Report a miscount** (`Session/MiscountReport.cs`): the last minute of reads (text), pickups and, if Steven says yes,
  pictures (changed ones only, loot list at most 1/s, 80 MB cap). Link at the bottom of the window; "Looks wrong?" on a drop
  also saves one. Switch in Options › Sharing (`UserPrefs.ReportFrames`). `replay <report>/trace.jsonl` and
  `report-replay <report>` replay it.
- Switches in settings.json: `ocr.autoScale`, `ocr.targetTextPx`, `ocr.nameColours`, `ocr.lootIcons`. The minute audit in
  reads.log counts what each part changed.

## Please do on the PC (in this order)

1. `KinahLedger.exe parse-test` (expect no MISMATCH) and `KinahLedger.exe ui-shot captures/ui --demo` plus
   `ui-shot captures/ui --options`: check the "Report a miscount" link in the status row fits beside the status text at
   662 px, and the new "Pictures in miscount reports" row on Options › Sharing.
2. **Loot list icon geometry (most important, never measured).** Run `KinahLedger.exe popup-test --image <picture>` on
   several `reward-shots\*-in-run.jpg` pictures where the loot list shows rows. For each row it prints the icon distances.
   Real matches should be well under 70 with the next icon clearly behind. If even right answers are above 70, or the
   right item isn't the closest, the crop is wrong: adjust `PopupIcons.Crops` (sizes 1.3–2.4 × the text height, gaps
   0.15–0.8 × height, left of the text) to the icon's real place, or `SureDistance`. If it can't be made sure, set
   `ocr.lootIcons` false in the shipped settings until it is.
3. **Text size.** `KinahLedger.exe ocr-test --scales` with the game open: the factor with the most "read exactly" is the
   best one for Steven's screen. Steven's text is probably over 18 px (5120×2160), so he stays at 2x; check that.
4. **Colours.** After 10 minutes of farming, `grade-colours.json` should hold 2+ grades with distinct colours. If every
   grade has the same colour, the game prints names in one colour and the feature does nothing (harmless).
   `ocr-test` prints the name colour of each line it reads.
5. Farm 15 minutes, then search reads.log for `is ... not ...: its colour`, `the run or the enemy's loot table`,
   `doesn't drop it`, `read as` (icons) and the `audit:` lines. Any wrong decision: press Report a miscount right after
   and keep the folder.

## Rules kept

The item, zone and enemy lists stay whitelists. Exact names are never second-guessed. When colour, tables or icons can't
decide, the old behaviour (the list's closest item) stands. Nothing new leaves the PC.
