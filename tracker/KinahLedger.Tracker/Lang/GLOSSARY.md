# Translation glossary (Korean, Traditional Chinese)

The tables in `Lang/ko/*.json` and `Lang/zh-TW/*.json` map the English text exactly as the code writes it to the translation (`Ui/Lang.cs`). Use these words every time so the app reads as one voice. Write the way Korean and Taiwanese MMO players talk: short, plain, no formal filler (Korean: 해요체 for sentences, noun phrases for labels; Chinese: Taiwan usage, 繁體, no mainland terms like 视频/质量 → use 影片/品質).
