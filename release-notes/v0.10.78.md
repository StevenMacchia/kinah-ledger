Kinah Ledger tracker 0.10.78: event timers.

- **Event timers.** The world boss timers' window is now **Timers** (the ⋯ menu on the Events page). At the top it counts down to the game's scheduled events: the Shugo Festival every hour, the Dimensional Invasion at half past, the Spacetime Rift every 3 hours and the Artifact Siege on Monday, Thursday and Saturday. Each says "On now" while it is on, and turns gold in its last 10 minutes. The world bosses are below, as before.
- **On the game's own clock.** The game's clock runs some seconds off your PC's (about 15 s on ours), and its events start on its clock. With packet reading on, the tracker takes the game's clock and counts on it, so the countdown hits zero when the event starts, not 15 s early. The window says which clock it is counting on.
- **The event you're in.** While you're in an event, the window shows it at the top: getting ready, under way, over (rewards next), then left.
- **Event runs start and end when the game says so.** With packet reading on, an event run now starts the moment the game puts you in the event (about 10 s before the minimap shows it), and ends when the game takes you out, instead of waiting for the screen. The screen still names the game when the tracker doesn't know it yet, and counts as before when packet reading is off.

Installed copies update by themselves in the background.
