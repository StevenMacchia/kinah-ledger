Kinah Ledger tracker 0.8.20: back-to-back expedition runs are saved as separate runs.

- Running the same expedition again and again (Urugugu Canyon five times in a row) is now saved as one run per clear, each with its own time, Kinah and items. Before, going back to the village and starting again carried on the same run, so five clears showed as one 37-minute run.
- A run ends once its reward screen is read and you move on to the next area; reward lines that print a few seconds late still go to the run they belong to.
- A second reward screen always starts a new run, and an empty read of the reward screen changes nothing.

Runs saved before this version are not changed.

Installed copies update by themselves in the background. Settings and history are kept.
