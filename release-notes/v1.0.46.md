Kinah Ledger 1.0.46: dungeon runs back to back, and five more counting fixes from a day of real play.

- **Back-to-back dungeon runs split where they should.** When a dungeon's room opens again after its last boss, in the same copy, that is a new run. The tracker used to keep both in one record until the next reward table, so a 7-minute run showed as 14 and took the next run's first gathers. Each run is its own record now.
- **A run's Kinah when its coin slot can't be read.** If the reward table's coin slot couldn't be read, the run kept 0 Kinah even though the game had just paid it. It now takes the payout the game counted with the table (960,000 for each Krao Cave run).
- **Your own Force loot.** When the game names you in a Force's loot line ("Swoly acquired Earth Dagger through Force distribution."), it's yours and counts. Other players' lines still don't.
- **No more extra gathers from a late chat line.** A chat line read slowly could count an ore or Odyle a second time. It's now matched to the gather it came from.
- **Quest turn-ins stay out of your farming.** A quest's bound Kinah and Abyss Points (50,000 bound Kinah and 2,500 Abyss Points, say) used to count as pickups when you turned it in between kills. They're kept apart now. Kill pay still counts as it comes.

Installed copies update by themselves in the background.
