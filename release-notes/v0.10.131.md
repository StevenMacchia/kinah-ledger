Kinah Ledger tracker 0.10.131: a DPS meter that's easier to read.

- **Outlined numbers.** Every DPS figure and percentage now has a tight dark outline, so it reads clearly over any bar or game scene. The DPS figures are a size bigger too.
- **White names.** Names used to be tinted in the class color, so they blended into that class's own bar. They're now white with the same outline. The class icon and the bar color still show the class.
- **Bars stay visible.** The bars are a shade deeper so the white text stands out on them, while staying easy to see.

Installed copies update by themselves in the background.
