Kinah Ledger tracker 0.10.101: running the same dungeon again is its own run.

- **One run per run.** In Full run, back-to-back runs of the same dungeon are separate records. Going back in after the last boss died starts a new run, and so does going back in with another group or pulling a boss you already killed there. A reconnect into the same run carries on.
- **One row per player.** You and each member show up as one row in a run, even after a reconnect.
- **A cleared run stays clean.** A run you cleared is no longer marked as partly counted when you head straight into the next one.
- **Always on** starts from 0 when you run the same dungeon again.

Installed copies update by themselves in the background.
