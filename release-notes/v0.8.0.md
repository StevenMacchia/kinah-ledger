Kinah Ledger tracker 0.8.0: an installer, steadier counting, and the game read even with a window over it.

**Install it**
- Download KinahLedger-Setup.exe and run it. It installs for your Windows user only (no administrator rights), adds Start menu and desktop shortcuts, and shows up in Windows Settings › Apps for a clean uninstall. Your settings and history are kept.
- Already on 0.7.x? This version arrives as usual, then offers to install itself. The old exe is removed once the installed one is running.
- Updates are small now: only what changed is downloaded, in the background, and applied when you close the tracker.
- Zones, events, enemies, loot tables and skins refresh between releases, so a new event zone works the same day.
- Windows may say "Windows protected your PC" the first time, because releases aren't code-signed yet. Choose More info › Run anyway.

**Counting**
- Kills come from all the evidence that agrees: the chat, the loot list beside your character and the Soul lines. One missing piece no longer loses a kill, and two pieces no longer count it twice.
- The game's Kinah counter checks the count; a pickup the chat missed is caught there.
- About three reads a second during fights.
- The game window is read directly, so a browser or pop-up over the chat is never read as loot.
- Inside an expedition or event, its loot belongs to the run; an expedition's areas count as one run under its name.

**New**
- Check the setup (Options › Game reading, and after the first-run screen): a step-by-step check that the chat, the loot list and the HP bar read, with what to change when one doesn't.
- Rare drop alerts: blue, gold and purple drops, and anything you mark Watch on its drop card, chime and light the in-game panel.
- Clear on Farming and Events, and a confirm before Crafting's Start over.
- Prices from 100,000 up read 680K and 1.68M, so they fit their columns.
- If English text recognition is missing from Windows, the tracker offers to add it.
