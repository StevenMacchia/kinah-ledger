Kinah Ledger 1.0.39: the site can tell an open tracker from a closed one.

- **An "I'm open" check every 5 minutes.** While the tracker is open and sharing is on, it tells kinahledger.com that it's running, including while the game is closed. It sends the app version, the install ID your runs already carry, whether the game is open, and which of your characters is counted (its number in the tracker, never its name). Nothing else goes with it.
- **The Share switch turns it off**, like everything else that's sent. Options › Sharing › What's sent lists it.

Installed copies update by themselves in the background.
