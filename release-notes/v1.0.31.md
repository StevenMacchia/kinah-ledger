Kinah Ledger 1.0.31: less memory again, and less work for your PC while you play.

- **Less memory.** Reading part of the game window used to copy the whole window into memory first, which on a big screen is two 44 MB pictures kept at all times. Now only the part being read is copied from the graphics card. On a 5120x2160 window that is about 110 MB less.
- **Less work while you play.** The same change cuts the tracker's own work for reading the screen to about a fifth.
- **Memory goes back sooner.** The tracker now tidies its memory when it gets gappy, instead of holding on to the space.

Installed copies update by themselves in the background.
