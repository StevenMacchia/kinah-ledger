Kinah Ledger tracker 0.9.10: the window says what it is waiting for, a "done" you can see, and keys for the everyday buttons.

- **The empty feed says what it is waiting for.** Before the first pickup it reads "Waiting for Aion 2 to start", then "Game found, looking for the chat" with a link to Options › Game reading, then "Ready. Pick something up and it shows here, newest first."
- **A dot shows how reading goes.** The line under the zone has a small dot: green while the chat is read, gold while the chat is looked for or out of view, red on a read problem. Click it for Options › Game reading.
- **A "done" shows where you look.** Picture copied, copied as text, goal set, server set and the like show in a small card at the bottom of the window for a moment, instead of the faint line at the foot. Warnings stay on that line.
- **Keys for the everyday buttons.** In the window, Ctrl+, opens Options, Ctrl+N starts a new session (with its Undo bar, as the button does) and Ctrl+Shift+C copies the share picture without opening Share. Each button's tooltip says its key.
- **The tray menu does more.** It has New session and Copy share picture, says Stop run while a run is on, and greys out what can't be done yet.
- **A button that is off says why.** Hover Start run before a server is chosen, or Share before the game is being read, and it tells you.

Installed copies update by themselves in the background.
