Kinah Ledger tracker 0.9.4: the Events page shows what you made, not how many runs were counted.

- **Best run on every place card.** The fourth figure on each expedition and event card is now your best run there, in place of the count of runs and the "why some aren't" link.
- **Cleaner Events lines.** The page line, the loot headings and Compare's last-run box no longer name how many runs were counted. Runs the tracker set aside still show in the runs table with their fix, and "Show all runs" still lists every one.

Installed copies update by themselves in the background. Settings, goals and history are kept.
