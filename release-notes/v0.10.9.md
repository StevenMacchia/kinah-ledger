Kinah Ledger tracker 0.10.9: three miscounts found in a day's own logs, fixed.

- **A pickup line read again without its count is the same line.** The chat cuts a long line at its edge or loses the count to a garble ("Acquired Fine Odyle x4." read once more as "Acquired Fine Odyle"), and the second reading was counted as one more pickup. The vote, the settle after reads that didn't line up and the watch on reads that didn't line up all take it for the line already counted now.
- **Another player's soul line with the name cut off is not your pickup.** "Psymonator[NEM] acquired Soul: Intermediate" wraps, and a read that lost the name left "acquired Soul: Intermediate", counted for the run as an item of that name. A line that begins with a lowercase "acquired" is someone else's.
- **A soul points line whose enemy name wraps counts.** "Obtained 10 Spirit King's Bodyguard Warrior" on one line and "Soul Points." on the next made no event, so that kill went unseen while the five single-line soul lines around it counted.
- **Quieter logs.** Trying whether two lines belong together no longer writes notes about the trial's made-up name ("not in the item list: mode Odyle"), which read like miscounts.
- **A log miner for the loop that found these.** `KinahLedger.exe log-mine` reads reads.log and trace.log and lists every place the tracker was unsure or overruled itself, each with the chat reads around it as a ready-made test case (tools/log-mine.md).

Installed copies update by themselves in the background.
