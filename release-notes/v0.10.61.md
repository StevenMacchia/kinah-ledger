Kinah Ledger tracker 0.10.61: old expedition runs are counted again, without the phantom gear.

- **Phantom gear taken out of past runs.** Before 0.10.54 the expedition reward table was sometimes read with extra rows of the floor under it, so runs were credited gear you never got, like an Urugugu run's "Tranquility Bow". A minute after this version starts, the tracker reads each old run's saved table picture again with the fixed reader, once, in the background. Where the new read is surely right, the run takes it: fewer slots, the phantom gear gone. Your Kinah is never changed, and any run it isn't sure about is left as it was.
- **The website follows.** Corrected runs are sent to kinahledger.com as corrections, so your profile and the areas' figures lose the phantom gear too.
- **A copy is kept.** Before changing anything it saves your old run list beside it (instances.pre-recount.jsonl). The reads.log line and recount.log say what changed.

Runs whose table picture is gone (pictures older than about a week are cleared to save space) stay as they are.

Installed copies update by themselves in the background.
