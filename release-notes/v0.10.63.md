Kinah Ledger tracker 0.10.63: Wrathful Ego counts.

- **Lookalike items in an expedition's reward table are named by the chat.** Wrathful Ego, Wrathful Will and Wrathful Mind share almost the same icon, so when the reward table's picture was blurry as it slid in, the tracker couldn't tell which one a slot was and counted none of them, while the chat line that said "Wrathful Ego acquired." was set aside for the table. Now a slot two lookalike icons can't call is named by the chat line that came with the table, so it counts once.
