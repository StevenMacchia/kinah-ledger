Kinah Ledger tracker 0.8.31: updates are checked every hour, and you choose when to install.

- The tracker now looks for a new version every hour instead of every six hours.
- When one is out, a window asks if you want to install it now. Yes installs it and the tracker opens again on the new version; No leaves it for later, and with automatic updates on (the default) it still installs by itself when you close the tracker.
- It never asks in the middle of a farming run: it waits until you stop the run. It asks once per version each time the tracker starts.
- No is the default answer, so a key pressed for the game can't restart the tracker by accident.

Installed copies update by themselves in the background. Settings and history are kept.
