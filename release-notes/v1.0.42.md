Kinah Ledger 1.0.42: four counting fixes found in a day of real play.

- **Abyss kills whose pay came first.** When a kill's bound Kinah, Rank Points and Abyss Points came a few seconds before the game said whose kill it was, the tracker sometimes took the pay for a reward and left it out. A Rank Points rise only ever comes from a kill, so that pay now counts right away.
- **Dungeon rewards with no name the tracker knows.** Inside a run, the game's own "No items available to acquire." line, wardrobe unlocks and half-read item names were sometimes counted as reward items. Only real reward names count now. The bigger effect: three of those lines in five minutes could make the tracker stop trusting the game's data for items for hours, so it fell back to reading the screen and missed drops. That no longer happens.
- **Two drops from one boss.** When a world boss dropped two items together and the chat named only one of them, the other could be left out. Both count now.
- **Kills that pay bound Kinah outside the Abyss.** On maps where every kill's Kinah is bound, a drop that came with a kill was sometimes set aside as box contents. It counts as a drop now. Quest payouts and boxes are still kept apart.

Installed copies update by themselves in the background.
