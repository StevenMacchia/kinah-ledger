Kinah Ledger tracker 0.10.65: reading the game's network traffic, beside the screen.

- **The tracker can read your Kinah from the game's own messages.** If Npcap (npcap.com) is installed, the tracker listens to the game server's messages to your PC and reads your Kinah balance from them, about a second before the chat shows the pickup. Running the tracker as administrator works too, without Npcap. Neither needs a second program. This first version changes no count. It writes what it saw to packets.log, with a once-a-minute line comparing it with the Kinah the chat reading counted, so the two can be checked over real play.
- **It only listens.** It reads a copy of the game's own connection and nothing else on your PC. Nothing is sent, the game isn't touched, and no packet is kept. Turn it off in Options › Game reading › Read the game's network traffic.

Installed copies update by themselves in the background.
