Kinah Ledger tracker 0.10.15: the panel over the game never brings the tracker's window up.

- **The panel never takes focus.** With the panel unlocked (so it can be dragged), a click that landed on it in the game activated it, and Windows brought the tracker's own window up over the game with it, where it stayed until you tabbed out. The panel now never takes focus, locked or unlocked; unlocked it can still be dragged, and locked it still lets clicks through to the game. A panel on an install from before the lock existed was left unlocked: Options › In game › Lock the panel makes clicks pass through it.

Installed copies update by themselves in the background.
