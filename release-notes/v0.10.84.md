Kinah Ledger tracker 0.10.84: event timers.

- **Event timers.** The world boss timers' window is now **Timers** (the ⋯ menu on the Events page). At the top it counts down to the game's scheduled events: the Shugo Festival every hour, the Dimensional Invasion at half past, the Spacetime Rift every 3 hours and the Artifact Siege. Each says "On now" while it is on, and turns gold in its last 10 minutes. The world bosses are below, as before.
- **Right to the second.** The countdowns hit zero when the event starts.
- **The event you're in.** While you're in an event, the window shows it at the top: getting ready, under way, over (rewards next), then left.
- **Event runs start and end on time.** An event run now starts the moment you're put in the event (about 10 s before the minimap shows it) and ends when you're taken out, instead of waiting for the screen. The screen still names the game when the tracker doesn't know it yet.

Installed copies update by themselves in the background.
