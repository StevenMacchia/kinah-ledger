Kinah Ledger tracker 0.9.13: one button to start fresh.

- **Start run is the fresh start.** Starting a run clears the counts on the tables and begins timing, with Undo if you didn't mean it. Undo brings the counts back and the run doesn't start; nothing is lost from the seconds in between. The Today strip keeps the day.
- **New session moved.** It is Clear everything in the ⋯ menu and the tray, with the same Undo, and Ctrl+N still does it. It clears without starting a run.
- **Less on the card.** Start run, Share and ⋯ are all that sit under the count now. Start run's tooltip says when pressing it will clear counts.

Installed copies update by themselves in the background.
