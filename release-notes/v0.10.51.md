Kinah Ledger tracker 0.10.51: each of your characters keeps its own numbers.

- **One set of numbers per character.** Today, the days on the Week side, your bests, the runs, goals and quest points are kept for each character on its own, so an alt's runs no longer mix into your main's rates. Prices, the item list and your settings stay shared, and the 1,000-a-day gathering limit is still counted per server, as the game counts it.
- **It knows who you're playing.** The tracker reads the class icon between your health and mana bars. When another character is in the world it closes the session as a character switch always did, then counts for that character. A loading screen no longer passes for a switch because the Kinah counter changed while it was up.
- **Your character at the top.** The window's header shows the character next to the server. Click it to name a character, to count for another one, or to start a new one for a second character of the same class (the icon can't tell those two apart).
- **Your history moves over.** The first character the tracker sees after the update takes everything kept so far. Runs whose pictures show another class's icon are then moved to that character, so recent alt runs land where they belong. Older runs, and days, goals and quest points from before the update, stay with the first character.

Installed copies update by themselves in the background.
