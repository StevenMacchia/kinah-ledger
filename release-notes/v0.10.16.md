Kinah Ledger tracker 0.10.16: one place at a time on the Expeditions and events page.

- **One place card, with a dropdown.** Under the ALL RUNS box the page showed the place being run open and every other place folded to a line each, which still ran the page off the bottom. Now there is one place card: the place being run (or the last one run) opens by default, and its band is a dropdown. Click the band to pick any place with runs, with its kind, how many runs, what they made and when it was last run beside each, and the card changes to it. A click on a run in the ALL RUNS box picks its place the same way and opens that run's sheet.

Installed copies update by themselves in the background.
