Kinah Ledger tracker 0.8.48: a new version shows up within about 10 minutes of its release instead of up to an hour.

- **Faster update checks.** The tracker looked for a new version once an hour, so a release could wait most of an hour before a running tracker noticed it (2026-10-27: 0.8.47 came out at 16:28, and a tracker started at 9:10 would only have looked at 17:11). It now reads the newest release's small version file every 10 minutes and does the full update check as soon as that file names a newer version. The hourly full check stays as a backstop. As before, the install question never interrupts a run or the game: it waits until you leave the game, and the overlay says an update is ready.

Installed copies update by themselves in the background. Settings and history are kept.
