Kinah Ledger tracker 0.10.40: lines that look alike are no longer taken for each other.

- **Leaving a dungeon room ends the run again.** The tracker took "Left Fire Temple Dungeon room." for the "Joined Fire Temple Dungeon room." line from a few minutes before, so it never saw you leave. Runs then ended only when their time for rewards ran out, and a reward that landed in that minute (a Handicrafter delivery, today) was listed under the run instead of the open world. Now the run ends when you leave the room.
- **A drop named like a reward is still a drop.** In the minute after a reward screen, a drop such as Order Greaves could be taken for the Order Gloves on the screen and set aside as its reward. Two different items are now always told apart.

Installed copies update by themselves in the background.
