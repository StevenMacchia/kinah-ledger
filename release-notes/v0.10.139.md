Kinah Ledger tracker 0.10.139: gear binds on equip, so the gear you get counts at its Market price.

- **Gear is worth something now.** All gear binds when you equip it, not when it drops. A piece from an expedition, a dungeon, an event, a box or a craft can be sold until you wear it, so it counts at the lowest Market price, after the Market's cut, like any other loot. Before, gear from a run was taken as bound and added nothing.
- **Bound copies still add nothing.** Some gear has a bound copy of its own, a separate item that can't be sold, and a reward table's gear is often that copy. That copy is counted, says "bound", and adds nothing. So does any item the game itself calls bound.
- **Everywhere it shows.** Run values, the Events page and its Gear row, the Today strips, Best drops, share pictures, the run list, Compare and Wrapped all follow the same rule. The Gear row now reads "19 gear · 2.4M" instead of "bound, no value", and still shows how many of each piece you got.
- **The site follows too.** Runs you share mark a bound copy of gear as bound, so kinahledger.com never prices it.
- **A piece you wear still counts.** The tracker can't see you equip gear, so a piece stays in the figures after you put it on.

Installed copies update by themselves in the background.
